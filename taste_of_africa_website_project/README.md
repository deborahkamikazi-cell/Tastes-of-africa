# Tastes of Africa Website

This project is the initial frontend scaffold for a multi-page website celebrating African culinary traditions.

## Project structure

```text
taste_of_africa_website_project/
├── index.html
├── pages/
│   ├── recipes.html
│   ├── regions.html
│   ├── about.html
│   ├── contact.html
│   └── recipes/
│       ├── jollof-rice.html
│       ├── injera.html
│       ├── isombe.html
│       ├── moroccan-tagine.html
│       └── bunny-chow.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   ├── icons/
│   └── videos/
├── README.md
└── .gitignore
```

## What each folder and file is for

- `index.html`: Landing page skeleton for the website.
- `pages/`: Contains secondary pages such as recipes, regions, about, and contact sections.
- `pages/recipes/`: Stores individual recipe detail pages.
- `css/styles.css`: Shared stylesheet for all pages.
- `js/script.js`: Shared JavaScript file for interactive behavior.
- `assets/images/`: Image assets to be added later.
- `assets/icons/`: Icon assets to be added later.
- `assets/videos/`: Video assets such as embedded media references or local files.
- `README.md`: Project overview and structure guide.
- `.gitignore`: Ignores OS and editor clutter.

## Notes

- HTML pages use semantic structure and relative file paths.
- CSS and JavaScript are separated and linked from each page.
- The project is intentionally scaffolded without final design content so the visual design can be implemented later from provided mockups.
